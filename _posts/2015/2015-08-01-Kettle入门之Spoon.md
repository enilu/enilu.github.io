Spoon 是 Pentaho Data Integration 中设计转换和作业的图形工具。一个“读 CSV、处理字段、输出 XML”的小流程，就可以说明数据在步骤之间怎样传递，以及清洗失败应该落在哪里。

## 先给输入和输出一个明确样例

以 PDI 5.3 的转换思路为例，输入 CSV：

```csv
name
Alice
Bob
```

目标是生成包含两条记录的 XML，并将姓名变为 hello:Alice、hello:Bob。先确定输入编码、表头、分隔符和引号规则，再配置步骤，避免预览成功却将整行读成一个字段。

## 用三个步骤连接转换

| 步骤 | 配置重点 |
|---|---|
| CSV 文件输入 | 文件路径、UTF-8、表头和 name 字段类型 |
| 字段处理 | 使用字符串拼接步骤，或用脚本生成新字段 greeting |
| XML 文件输出 | 根节点、记录节点、输出字段及编码 |

将步骤按主输出方向连接，在预览中检查每一步的字段值与类型。只是给姓名加前缀，不一定要使用 JavaScript；现成转换步骤更容易让维护者看懂。

## 异常数据也要有出口

空姓名、重复行、引号内逗号和无法解码的内容都应准备样本。按业务需要过滤、标记或进入错误输出，不要无声地跳过。XML 中的特殊字符也应由输出组件正确转义，不能用手工拼字符串替代。

## 从预览走到可重复运行

一次转换描述数据流，作业可以组织多个转换的执行顺序与失败分支，两者不是完全相同的概念。保存转换文件，并将路径、环境参数和输出命名集中管理，避免把开发机绝对路径固化在每个步骤里。

重复运行时明确覆盖还是追加，执行结束后核对输入、成功、失败和输出记录数，并重新解析生成的 XML。只有输出文件存在，并不能证明所有行都被正确处理。

参考：[Pentaho Data Integration 文档](https://docs.pentaho.com/)。
